# POSLATOR

A polished Next.js starter for a US-focused calculator and everyday-tools website.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Stack
- Next.js 15
- React 19
- Custom CSS (no Tailwind dependency)
- Client-side calculator logic

## Current tools
16 working calculators covering work/time, money/pay, everyday math, loans/cars, dates and unit conversion.

## Before launch
- Buy/connect your real domain (POSLATOR.com if you own it)
